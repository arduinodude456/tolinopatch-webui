Features

KFMon
KFMon für Tolino V5.x installieren
KOReader
Automatisch den KOReader aus koreader/ verwenden
KOReader wird automatisch aus koreader/ geladen.
KOReader Startbild
Die im KFMon-Paket enthaltene koreader.png wird automatisch übernommen.

ZIP-Struktur

Advanced · Kobo eReader.conf

Optionen für .kobo/Kobo/Kobo eReader.conf.

[FeatureSettings]

BookSpecificStats
Lesestatistik im Buch-Kontextmenü.
ExportHighlights
Export von Anmerkungen ermöglichen.
Screenshots
Screenshot-Funktion aktivieren.
FullScreenBrowser
Browser im Vollbildmodus.
InvertScreen
Bildschirmdarstellung invertieren.
MyWords
MyWords aktivieren.

[ApplicationPreferences]

SideloadedMode
Sideloaded-Modus aktivieren.
AIRPLANE_MODE
Flugmodus aktivieren.

[DeveloperSettings]

AutoUsbGadget
USB-Gadget automatisch aktivieren.
ForceAllowLandscape
Landscape-Modus erlauben.
ForceWifiOn
WLAN eingeschaltet halten.

[Reading]

swipeBrightness
Helligkeit per Wischgeste.
numPartialUpdatePageTurns
Anzahl der Teilaktualisierungen.
readingFontFamily
Leseschrift.
readingFontSize
Leseschriftgröße.
readingLineHeight
Zeilenhöhe.

[PowerOptions]

UnlockEnabled
Swipe-to-Unlock.
FrontLightState
Frontlight beim Start aktivieren.
FrontLightLevel
Frontlight-Level 0–100.
AutoOffMinutes
Automatisches Ausschalten.
AutoSleepMinutes
Automatischer Sleep.
ShowBookCover
Buchcover auf dem Sleep-Screen.

Die Einstellungen werden nur in die Konfiguration geschrieben, wenn sie aktiviert bzw. ausgefüllt wurden. Nicht jede Option funktioniert auf jeder Firmware.
